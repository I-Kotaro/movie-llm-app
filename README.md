# AI分析型 映画提案アプリ (ポートフォリオ)

Laravel を使用し、
**AIを活用した映画提案Webアプリ**を開発しました。<br>
曖昧な気分や感情をチャットに入力するだけで、Gemini API(LLM)とTMDB APIを連携し、今すぐ観たくなる映画を3つ提案します。<br>
「作品数が多くて選べない」という選択のパラドックスを解決し、迷わず映画を決められることを目的としてロジック設計を行っています。<br>

## 開発の経緯

私自身が映画好きで、休日に「今の自分の気分に合った映画を観たい」と思うことがよくありました。<br>
しかし、従来の検索サービスでは「ジャンル」や「公開年」などの決まった枠組みでしか絞り込むことができず、「丁度良い怖さのホラー映画」「仕事の疲れを吹き飛ばすような爽快な映画」といった自分の感情やニュアンスで探すのが非常に困難でした。<br>

そこで、 **自分の今の気分をそのままチャットに打ち込むだけで、AIが最適な映画をコンシェルジュのように提案してくれるサービスがあれば、映画選びがもっと楽しくなるのではないか** と考え、本アプリを開発しました。

## 苦労点・気付き・学び

### AIのハルシネーションを防ぐためのアーキテクチャ
AI単体に「おすすめの映画を教えて」と聞くと、実在しない映画をでっち上げたり、あらすじを捏造するハルシネーション問題がありました。<br>
これを防ぐため、**「LLM（ユーザーの意図抽出） → TMDB API（正確な実在データの検索） → LLM（検索結果から自然な提案文章を生成）」** という3ステップのパイプラインを構築しました。外部の信頼できるデータベース（TMDB）を経由することで、絶対に嘘をつかないコンシェルジュを実現できました。

### プロンプトインジェクション対策とLLMフォールバック制御
AIが「明日の天気は？」といった映画以外の質問にも答えてしまう問題が発生しました。<br>
対策として、システムプロンプトに強力なガードレールを設けることで、映画以外の話題をシャットアウトするよう制御しました。また、APIの制限や障害に備え、複数のGeminiモデルを順番に試し、最終的にはGroqへフォールバックする堅牢なエラーハンドリングを実装しました。
